# KTU GPA CALCULATOR (2019 SCHEME)
A simple and clean web application to calculate SGPA and CGPA for students following the KTU 2019 Scheme

---

## Features
- Select your branch and automatically load all semesters and subjects
- Subjects and credits are pre-filled based on the selected branch
- Just enter your grades to calculate SGPA and CGPA instantly
- Supports multiple branches and semesters
- Clean and minimal user interface for fast and comfortable usage
- Ability to add custom subjects manually
- Displays earned credits along with GPA calculations
- Built completely using HTML, CSS, and JavaScript

## How It Works
1. Open the homepage
2. Select your branch
3. Semester subjects and credits will load automatically
4. Enter your grades for each subject
5. Click:
  - Calculate → to get SGPA for a semester
  - Calculate CGPA → to get overall CGPA
6. Optionally add custom subjects if needed

## Running the Project
### Using VS Code Live Server
1. Install the Live Server extension in VS Code
2. Open the project folder
3. Right click homepage.html
4. Click Open with Live Server
The app should run at:
```bash
http://127.0.0.1:5500/
```
